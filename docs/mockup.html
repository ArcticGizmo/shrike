The snip tool that never throws you across desktops.

Shrike is a tray-resident capture studio for Windows: instant screenshots with real annotation, screen recording with lightweight timeline trimming, and export presets that keep a Slack clip in the kilobytes. Built on Avalonia — sibling to sprig — with snappy loading as the first commandment.

Avalonia 12 · .NET 10 Tray-resident, <100ms to overlay Windows-first (WGC) Dark-native

02

The headline: no desktop teleport

The single most-hated Snip behaviour is that invoking it activates its existing window — which may live on another virtual desktop — and Windows drags you there. Shrike refuses to.

Windows Snip — today
Yanks you to Desktop 3
Desktop 1 · you are here

Shrike
Opens right here
Desktop 1 · you are here
stay
Desktop 3 · undisturbed

The overlay is born fresh on the current desktop every time. For the editor, Shrike checks IVirtualDesktopManager and either moves the window to you or opens a new instance here — your choice in settings. Never a switch.

03

Always resident, instantly ready

Shrike sits in the tray so the expensive costs — CLR, Avalonia, the capture device — are paid once at login. A hotkey is all it takes.

Shrike● ready
Capture region Ctrl+Shift+2
Capture window Ctrl+Shift+3
Record screen Ctrl+Shift+5
Recent — click to re-copy

Snappy above all

Overlay in <100 ms, editor in <250 ms. Single-instance guard signals the resident process over a named pipe instead of spawning a cold start. A startup-budget test guards it in CI.

One annotation model

Text, shapes, scribble, arrows, highlighter, redaction and step badges — non-destructive vector layers with undo/redo. The same model will later pin drawings to a recording's timeline.

Footprint on a dial

Export presets and a live size estimate turn a screen recording from tens of megabytes into a Slack-sized clip — downsample, cap fps, pick codec, watch the number fall before you share.

04

What's in v1 — and what's parked

In v1 · screenshots

Region / window / monitor capture · delay timer · annotation toolbox · recent-captures ring · copy (PNG + DIB) · save (PNG/JPG/WebP) · rebindable hotkeys.

In v1 · recording

Region recording · floating HUD · non-destructive timeline trimming · export presets with live size estimate · copy-as-file or save with downsampling.

Parked (future)

Timeline keyframes for timed text / drawings · audio capture · scrolling capture · OCR · GIF captions · cloud share links · cross-platform.

Open questions for your review: autostart default · persist the recent-ring to disk or memory-only · final hotkey set · ship the CLI in v1? · blur vs true-destructive redaction · audio as fast-follow. Full detail in docs/design.md.
